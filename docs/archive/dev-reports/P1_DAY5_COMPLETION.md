## 🎓 知识库

### 项目架构

```
UsageSync 系统架构
├─ 同步层 (7 个同步器)
│  ├─ AnthropicSync
│  ├─ OpenAISync
│  ├─ ZhiPuSync
│  ├─ GitHubSync
│  ├─ GeminiSync
│  ├─ DeepSeekSync
│  └─ SiliconFlowSync
├─ 数据层 (数据处理)
│  ├─ Validator (验证)
│  ├─ CostCalculator (计算)
│  ├─ DataTagger (标记)
│  └─ Types (数据模型)
├─ 协调层 (同步协调)
│  └─ UsageSyncCoordinator
├─ 界面层 (CLI)
│  └─ UsageSyncCLI
└─ 认证层 (OpenCode)
   └─ fromOpenCodeAuth()
```

### 数据流

```
用户指令
  ↓
CLI 解析
  ↓
Coordinator 协调
  ↓
7 个同步器并发
  ↓
数据获取 (多个 API)
  ↓
Validator 验证
  ↓
CostCalculator 计算
  ↓
DataTagger 标记
  ↓
输出报告/配置
```

### 关键设计决策

1. **多同步器架构** - 支持 7 个独立的厂商
2. **并发处理** - 多个同步器并行运行
3. **分层验证** - 多层次的数据验证
