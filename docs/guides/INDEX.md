## 快速开始

### 3 分钟安装

```bash
# 1. 安装依赖
bun install

# 2. 配置认证（以 Anthropic 为例）
opencode login anthropic

# 3. 运行首次同步
bun run Tools/UsageSync/CLI.ts sync
```

### 验证安装

```bash
# 检查连接状态
bun run Tools/UsageSync/CLI.ts health

# 应该看到
✓ anthropic    已配置
✓ openai       已配置
✓ 其他厂商...

# 生成报告
bun run Tools/UsageSync/CLI.ts report
```
